# Ejecutar en Visual Studio Code

1. Instala Flutter estable y las extensiones Flutter y Dart de VS Code.
2. Descarga el repositorio y abre la carpeta que contiene `pubspec.yaml`.
3. Ejecuta `flutter doctor` y `flutter pub get` en la terminal.
4. Si VS Code solicita el SDK, selecciona la carpeta de tu instalación de Flutter.
5. En Run and Debug selecciona **Tienda Aula · Navegador** y pulsa F5.
6. Cuando el servidor esté listo, abre http://127.0.0.1:8765.

Cuenta pública de cliente: usuario `donero`, contraseña `ewedon`.

Para ejecutar en un teléfono o emulador configurado, usa `flutter run` y selecciona el dispositivo. Para detener la ejecución de VS Code, pulsa Shift + F5.

La configuración compartida no depende de las rutas del equipo del autor.
